# クッキー型デザイナー

クッキーの**抜き型**と**スタンプ**を、ブラウザで設計して3Dプリンタ用のSTLに書き出せるツールです。

**→ https://tools.oyabe-craft.com/cookie-cutter/**

作者: [オヤベクラフト](https://oyabe-craft.com/)

## できること

- 点とベジェ曲線で輪郭を描く（Inkscapeのような操作）
- 内側に絵柄（線・面）を描く。スタンプの凸リブになる
- 画像を下絵として重ね、その上をなぞる
- 3Dプレビューを見ながら寸法を調整
- **STL** 書き出し（抜き枠 / スタンプ / 両方をまとめて）
- **SVG** 書き出し（実寸1:1の線データ。輪郭だけ・絵柄だけも可）

すべてブラウザの中で動きます。**画像や設計データがサーバーに送られることはありません。**

## 印刷の助けになる機能

3Dプリントで失敗しやすい箇所を、印刷する前に知らせます。

- **壁の厚みをノズル幅の整数倍に丸める** — 半端な厚みは層に空隙ができて刃が割れます
- **細すぎる絵柄の警告** — 焼くと模様が消えます。「絵柄を太らせる」で一括して直せます
- **鋭すぎる角・小さすぎる曲率の検出** — 画面上に印が出ます
- **細すぎるくびれの検出** — 壁どうしがぶつかって潰れます

## 使い方

1. **枠** タブで外形を描く
2. **絵柄** タブで模様を描く
3. 右のパラメータで寸法を調整
4. **エクスポート** → 3Dプリント用（STL）→ 両方まとめて

抜き枠は刃を下にして、スタンプは模様の面を上にして印刷してください。

## 安全と法律について

アプリ内の「**使う前に**」に記載しています。要点だけ書くと、

- 3Dプリンタで作る型は、ふつう食品衛生法の規格に適合しているか確認されていません
- 自分で作って自分で使う分には、食品衛生法の禁止行為に当たらないと考えられます
- **型そのものを売る場合、または販売する食品を作るために型を使う場合は、管轄の保健所に相談してください**
- 積層の溝に汚れが残る可能性があります。食品用のラップやフィルムを介して使うことをおすすめします

法的な助言ではありません。詳しくはアプリ内の記載をご覧ください。

## 開発

```bash
pnpm install
pnpm dev      # http://localhost:5174
pnpm test     # 形状生成とパス編集の検証
pnpm build
```

構成は Vite + TypeScript。フレームワークは使っていません。依存は `three`（3D表示）、`clipper-lib`（線の太らせ・オフセット）、`earcut`（面の三角形分割）だけです。

設計の意図と調べた内容は `docs/` にあります。

- `docs/SPEC.md` — データ構造、形状生成の考え方、寸法の既定値と根拠
- `docs/RESEARCH.md` — 既存ツールの調査、設計寸法の出典、法令の整理
